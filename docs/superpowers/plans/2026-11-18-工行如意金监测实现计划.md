# 工行如意金监测 Realization Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Electron + Vue3「攒金小本本」：工行如意金实时价、上金所走势、账本与提醒，可打 Win/Mac 包。

**Architecture:** 主进程拉工行 A00505 与上金所 Dailyhq/quotations，IPC 给渲染进程；账本/设置 localStorage；SCSS 主题变量；C1 粉紫梦核 + L2 分栏。

**Tech Stack:** electron-vite、Electron、Vue 3、Sass、echarts、electron-builder

**Spec:** `docs/superpowers/specs/2026-11-18-工行如意金监测与账本提醒.md`

## Global Constraints

- 仅 Electron，不做静态网页模式
- 渲染进程不直连工行/上金所
- 样式禁止硬编码 hex，走 SCSS/CSS 变量
- 人类可读，禁止过度设计
