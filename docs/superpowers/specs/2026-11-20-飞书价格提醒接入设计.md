# 飞书价格提醒接入设计

日期：2026-11-20
状态：已确认方案，待实现

## 背景

应用已有三类价格提醒（接近均价、上涨分档、下跌分档），触发后只弹系统通知。系统通知在锁屏、离机、手机端容易错过。希望把提醒同步发到飞书。

## 收费与接入方式

飞书通知本身不收费。可选路径：

- 群自定义机器人 Webhook：免费、无需管理员审批。群设置 → 群机器人 → 添加自定义机器人 → 复制 Webhook 地址。支持可选「签名校验」。
- 企业自建应用机器人：免费创建，但需管理员开通 `im:message:send_as_bot` 并发布版本，适合私聊推送。

本期选择**群自定义机器人 Webhook**：配置成本最低，满足「提醒不漏」的核心诉求。

## 目标

- 现有三类提醒触发时，飞书群收到一条消息，与系统通知内容一致。
- 设置页可开启/关闭、填写 Webhook、可选签名密钥、发送测试消息。
- 发送失败不影响系统通知与提醒状态落盘。

## 非目标

- 私聊推送（不做自建应用、OAuth、open_id）。
- 消息卡片、@人、按钮交互。
- 每日行情播报、按价格变动幅度推送。
- 多渠道路由抽象（系统通知 + 飞书两个渠道，先不抽 provider）。

## 架构

```
ICBC 报价轮询 (poller)
  → processQuoteAlerts(quote)            // src/main/alert-engine.js
      → evaluateAlert / evaluateChangeAlert // 判定逻辑
      → showSystemNotification            // 现有
      → sendFeishuBotMessage              // 新增，fire-and-forget
      → broadcast('golden:alert')         // 现有
```

### 发送模块 `src/main/feishu.js`

- `sendFeishuBotMessage({ webhook, secret, text }) -> Promise<{ ok, error }>`
- 使用全局 `fetch`，`AbortController` 8 秒超时。
- 请求体：`{ msg_type: 'text', content: { text } }`；填了密钥时追加 `timestamp`、`sign`。
- 加签：`sign = base64(HMAC-SHA256(key = timestamp + "\n" + secret, data = ""))`，实现后用测试按钮以真实机器人验证。
- Webhook 必须以 `https://open.feishu.cn/open-apis/bot/v2/hook/` 开头，否则直接返回错误。
- 飞书返回 `code === 0` 视为成功；否则返回 `{ ok: false, error: "code msg" }`。
- 网络错误重试 1 次（间隔 1 秒）；仍失败只写主进程日志。

### 触发点 `processQuoteAlerts`

- 组装备忘消息：原有提醒文案 + 持仓行（`grams > 0` 时）：
  ```
  【攒金小本本】接近均价提醒
  赎回价 1108.00 元/克 · 距均价 -2.00
  持仓 20.000g · 均价 1110.00 · 浮盈 +¥360.00
  ```
- 持仓数据复用已加载的 `entries`（`weightedAvgFromEntries`），市值 = 克数 × 当前赎回价，浮盈亏 = 市值 − 成本。
- `void sendFeishuBotMessage(...)` 调用，避免阻塞提醒状态保存与系统通知。

## 设置项

`settings.json` 新增三个字段（主进程 `settings-store.js` 与渲染层 `stores/settings.js` 同步）：

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `feishuEnabled` | boolean | false | 是否发送飞书消息 |
| `feishuWebhook` | string | '' | 机器人 Webhook 地址 |
| `feishuSecret` | string | '' | 签名密钥，可空 |

`normalizeSettings` 中对 webhook / secret 做 trim；未知或非法地址不阻止保存，但发送时直接返回错误提示。

### UI：价格通知 Tab 新增「飞书通知」分组

- 启用开关。
- Webhook 地址：password 输入 + 显示切换。
- 签名密钥：password 输入 + 显示切换，标注「可选，机器人开启签名校验时填写」。

### IPC

- preload 暴露 `testFeishu(payload)`。

## 错误处理

- 开关关闭或 webhook 为空：静默跳过，不产生日志噪音。
- 地址不合法：测试按钮展示「Webhook 地址不合法」；自动发送写日志。
- 飞书返回非 0 code：记录 code/msg，测试按钮展示。
- 网络失败：重试 1 次后放弃，不影响系统通知。
- 触发频率低（分档提醒），不需要发送队列或限频逻辑。

## 安全

- Webhook 等同于群发权限，泄露后任何人都能向群发消息。
- 当前保存在本地 `settings.json`（明文），设置页用密码框显示，日志对地址打码。
- 系统钥匙串加密不在本期范围。
